# Project Discovery & Systems Analysis Playbook
This playbook is a structured framework used to guide project discovery, analyze system impacts, and align business and technology teams before delivery.
## Overview
The goal of this playbook is to ensure that every project is clearly defined, dependencies are understood, and risks are identified early in the process.
## What This Covers
- Business objective and intake
- Scope definition (in scope vs out of scope)
- System and platform identification
- Upstream and downstream dependencies
- Data impact and integration analysis
- Process and workflow changes
- Risks, assumptions, and dependencies
- Testing strategy and delivery planning
## How It’s Used
This framework is used during the early stages of a project to:
- Ask the right questions
- Identify impacted systems and teams
- Prevent gaps in requirements
- Improve communication between business and technology
